# طابعة الصور الاحترافية - A4 Photo Printer

ملف HTML واحد احترافي لطباعة الصور المتعددة على ورق A4 بتحكم كامل.

## 🎯 الفكرة
تطبيق ويب يعمل محلياً (بدون خادم) يسمح لك برفع عدد كبير من الصور من جهازك، وتحديد كم صورة تريد طباعتها في صفحة A4 واحدة، مع معاينة حية دقيقة لما سيتم طباعته.

## ✨ المميزات

### 1. رفع الصور
- سحب وإفلات (Drag & Drop) يدعم مئات الصور دفعة واحدة
- اختيار متعدد من الجهاز
- يدعم JPG, PNG, WEBP وجميع صيغ الصور
- عرض فوري مع اسم وحجم كل صورة

### 2. تخطيط الطباعة
- **عدد الصور في الصفحة:** 1, 2, 4, 6, 8, 9, 12, 16 + تحكم مخصص (أعمدة × صفوف)
- **اتجاه الورقة:** عمودي Portrait / أفقي Landscape مع تحديث تلقائي لـ @page
- **الهوامش:** بدون، صغير 3mm، متوسط 8mm، كبير 12mm، كبير جداً 18mm
- **المسافة بين الصور:** 0mm إلى 8mm
- **طريقة عرض الصورة:** 
  - احتواء كامل (contain) - يحافظ على النسبة
  - ملء المربع (cover) - قد يقص الأطراف
  - تمديد (fill)

### 3. المظهر والتشطيب
- إطار خفيف حول كل صورة
- زوايا دائرية ناعمة
- علامات القص للمساعدة في التقطيع بعد الطباعة
- ترقيم الصفحات في المعاينة
- خلفية بيضاء نظيفة للطباعة

### 4. إدارة الصور
- إعادة ترتيب بالسحب والإفلات
- تدوير كل صورة 90° (مع حفظ حالة التدوير)
- حذف فردي مع تحرير الذاكرة (revokeObjectURL)
- مسح الكل مع تأكيد
- ترتيب عشوائي / عكس الترتيب
- عداد مباشر: إجمالي الصور وعدد صفحات A4

### 5. المعاينة والطباعة
- معاينة حية 100% مطابقة للطباعة الفعلية
- كل صفحة تمثل ورقة A4 حقيقية بمقاس 210×297mm
- حساب تلقائي لعدد الصفحات = ceil(إجمالي الصور / (أعمدة×صفوف))
- طباعة احترافية: إخفاء واجهة التطبيق وإظهار صفحات A4 فقط
- دعم @page size مع portrait/landscape ديناميكي
- page-break-after: always لكل صفحة

## 🚀 طريقة الاستخدام
1. افتح ملف `index.html` في المتصفح
2. اسحب صورك إلى منطقة الرفع أو اضغط للاختيار
3. من اللوحة الجانبية اختر:
   - كم صورة في الصفحة (مثلاً 4 صور = 2×2)
   - اتجاه الورقة
   - الهوامش والمسافات
4. راجع المعاينة الحية على اليمين
5. أعد ترتيب الصور بالسحب إذا لزم الأمر
6. اضغط **طباعة الآن** أو Ctrl+P

## 🖨️ مواصفات الطباعة
- مقاس: A4 (210×297mm)
- اتجاه: Portrait / Landscape (قابل للتبديل)
- CSS: @page { size: A4 portrait/landscape; margin:0 }
- الطباعة تطبع صفحات A4 فقط بدون واجهة
- كل صفحة page-break-after: always

## 💻 التقنيات
- HTML5 + CSS3 + Vanilla JavaScript (بدون مكتبات خارجية)
- File API + URL.createObjectURL للأداء
- CSS Grid لتخطيط الصور
- Responsive Design + RTL عربي
- يعمل Offline تماماً

## 📱 متجاوب
- يعمل على الهاتف والكمبيوتر
- على الشاشات الصغيرة: الشريط الجانبي يصبح علوي
- ورقة A4 تحافظ على نسبتها مع max-width

## 🔧 التطوير
الملف واحد فقط `index.html` يحتوي كل شيء (CSS + JS) لسهولة النقل والمشاركة.
